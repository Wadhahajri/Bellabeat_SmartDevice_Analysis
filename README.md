# Bellabeat Smart Device Usage Analysis

A data analysis case study exploring smart device usage patterns using Excel and Power BI to generate business insights and recommendations for Bellabeat.

---

##  Project Overview

This project analyzes Fitbit smart device usage data to identify patterns in user activity, daily behavior and sleep.

The analysis follows the data analysis process of asking business questions, preparing and cleaning the data, analyzing trends, visualizing findings and developing business recommendations.

The project was completed as part of the Google Data Analytics Professional Certificate case study.

---

##  Business Task

The goal of this analysis is to identify trends in smart device usage and explore how these insights could support Bellabeat's marketing strategy and customer engagement.

### Business Questions

- What are the main trends in smart device usage?
- How can these trends be applied to Bellabeat customers?
- How can the findings support Bellabeat's marketing strategy?

---

##  Dataset

The dataset used for this project is the Fitbit Fitness Tracker Data.

The dataset includes information related to:

- Daily activity
- Steps
- Calories
- Sleep
- Heart rate
- Activity intensity

The version used in this analysis contains data from 33 users.

### Data Source

The dataset used in this project is the **FitBit Fitness Tracker Data**, made available on Kaggle by **Möbius**.

The dataset was collected from Fitbit users who consented to share their personal tracker data. It contains detailed tracking information, including activity, heart rate, and sleep monitoring, with some data recorded at the minute level.

For this project, the analysis focused primarily on the **daily activity and sleep data** relevant to understanding user activity patterns, sedentary behavior, and sleep duration.

[FitBit Fitness Tracker Data – Kaggle](https://www.kaggle.com/arashnic/fitbit)

### Data Limitations

The dataset has several limitations:

- Small sample size
- Older data
- Limited demographic information
- Fitbit users may not represent Bellabeat customers

Therefore, the findings should be interpreted as directional insights rather than representative results for all smart device users.

##  Analysis

The analysis focused on identifying behavioral patterns through:

- Average daily steps
- Average steps by day type
- Average steps by hour
- Peak activity hour
- Sedentary activity
- Sleep duration
- Activity levels

Excel was used for data cleaning and preparation, while Power BI was used to create interactive visualizations and the final dashboard.

---

##  Key Findings

### 1. Weekday Activity

Average daily steps were approximately **17% higher on weekdays** compared with weekends.

### 2. Peak Activity

The highest average activity occurred around **7 PM**, indicating an evening activity pattern.

### 3. Sedentary Behavior

Approximately **83% of tracked activity-level time was sedentary**.

### 4. Sleep Duration

The **6–8 hour** range was the most common sleep duration among the users analyzed.

##  Business Recommendations

Based on the findings, the following recommendations were developed:

### Personalized Activity Reminders

Use sedentary-time patterns to provide personalized activity reminders and encourage users to move throughout the day.

### Evening Activity Campaigns

Use the observed 7 PM activity peak to develop evening-focused engagement campaigns and activity challenges.

### Personalized Sleep Insights

Use sleep-duration patterns to provide personalized wellness insights and encourage healthier sleep habits.

The analysis is based on a small Fitbit dataset and does not include detailed demographic information or Bellabeat-specific customer data.

The findings therefore provide useful directional insights but should not be generalized to all Bellabeat customers.

Future analysis could incorporate:
